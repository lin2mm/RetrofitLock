## 1. 产品外形/外观禁止项
- 不从面盖视觉稿反推外壳厚度、尺寸或 R 角（94 / StartHere）
- 不恢复、不引用 superseded 链：R19/R20 冻结图、ImmutableCrop_v2（含 100/100）、31/33 provisional、历史派生 Hero 图、Registry §10 排序
- **109 = rejected-by-user**：电池盖贴到顶部圆弧端的画法，禁止复活
- 禁止引用：97–100 错误渲染链、71–93 底部塑料推断链、v4 旋钮资产（v4 裁剪/网格/角度图，96 清单）
- 组合规则（94）：成品图只允许 **真实铝壳 + 确认面盖 + 确认旋钮 + 唯一底部电池盖**；内部件不得出现
- 不画不猜：背面、侧面底部、接口、内部件（O9：确认稿=单张 3/4 视角，其余不可见）
- 不自行改变产品外框、底部电池盖、面盖轮廓或旋钮（102 §7 不可变禁令）
- 不从文件名、BOM 角色、颜色、坐标交叠、图像"合理性"推断未确认结构（101/102）
- 不把旧 provisional 装配或旧图写成工程事实；不从原始塑料 STEP 自行推导外部可见性（StartHere）
- 不生成任何底部塑料件或内部配件的 CAD 预览（StartHere）
- 对外图禁止出现：CAD 坐标轴（O7）、螺丝/接口/键盘/扬声器孔/摄像头（QA 红项）
- 确认稿只决定面盖外观与旋钮；**装配关系仍需 CAD 证据**（O8；不得用视觉稿证明装配）
- 31 图只作相机/构图参考；其黑色壳、旧旋钮外观、假设隐藏面不得当最新产品事实（102 §3A）
- 电池盒筋：按确认稿画（确认稿有筋；104 漏了 → 必须补）；4 条深凹槽/喇叭格栅感 = 错（O8 + 干扰台账）
- 旋钮禁止项：凸起把手（v1/v2 错）、胶囊端/圆头端、金属套/装饰环/槽/齿/十字纹/额外间隙（KNOB_LOG §1）
- 纹理禁止项：木纹、皮革粒（O6 + 干扰台账）；壳色禁止深炭黑方向（A01 历史方向待终审）

## 2. 数字与测量禁止项
- 外壳尺寸只认 `sx-db-4.stp` 包络 39.8×22.5×90.5；轮廓 = 上端半圆 R19.9 / 直段 65.6 / 下端平直 29.8 + R4.8（R17 原文复核）
- 内部工程数字（face/edge/vertex、local bbox、体积、placements、Slider 边、15.18mm³ 等）**已删出仓库，禁止从记忆或旧文件搬回**（R16）；Tier 1 时从 Drive `107/111` 重取
- AI 不画数字：尺寸标注 = 文字后期叠加（naming.md `dims_annotated`）
- 剪影比例必须 PIL 实测，不信任 prompt 自报（Tier 0 快检：正拍 0.44 / 25° 剪影 0.50 ±6%）
- 无工程证据不写：公差、扭矩、防水、寿命、拆装步骤（K12）

## 3. 声称与状态禁止项
- "用户已上传 X" 必须有一次文件系统证据（`verify-upload.sh`）；没落地 = 明说没落地，不出正式图
- 不因"用户说已上传/已确认"就声称已读取/已校验/已同步（Agent read 门槛）
- 能力声称先实测，不凭记忆/直觉（probe-before-promise / two-network-paths / sandbox-capability-probe-not-memory）
- claim 纪律：每条声称带证据标签（`01_EXP1-A01`）；未确认功能不入文案（O3 LED=暂定 → 图上保留、文案不写死）
- 合规话术：不夸大 HomeKit / Matter / BHMA / ANSI；面盖对外 = fine-textured polymer（禁 wood/leather）；壳对外 = Aluminum Case
- 不把已删除的本地路径称为当前可读取文件
- 银黑转换、材质牌号、工艺 = 需用户确认后才能写（01_EXP1-A01）

## 4. 流程禁止项

- **聊天附件 = 临时件**：读 → 存结论进 md → 删；永不推 GitHub（R13 用户长期指令）
- 删除错误资产前：先建 manifest、先更新引用、**不删除错误审计本身**（102 §5.4/5.5）
