# How to extract the question comparison

This is the method. It is not a result. No wording has won. No country is selected.

## What to read

Read only the logs that contain the sentence actually sent and the reply. The current named source is `07_SL-H08_Outreach_Status_Feedback_Log_NoSend_CN_v1.md` in `20260923-Session10`. Wave reply logs, if a later file names them, are the same kind of source.

Do not read a lead spreadsheet as if it were the question. Do not copy a name, email, phone, or company into this file.

## One row per reply

| Field | Write | Do not write |
|---|---|---|
| Wave | 1, 2, or 3, only if the log says it | A guessed wave |
| Question | The sentence that was sent, shortened to the ask | The whole message if it contains a person |
| Reply | Asked for a catalogue, or another reply type | A purchase, a chosen channel, or a country rank |
| Same wording | Yes, if this sentence already has a row | A new row for a spelling-only difference |

## When a question can be called stronger

Only after the same wording has catalogue replies in more than one wave. Even then it does not choose a sales country, a channel, or a winner to send.
