# SHORTPATH_IMAGES_CN_v1 — 产品图分型与外观图最短路径（2026-09-20）

> 起因：用户（R15）批评「上一个 session 无数动作死磕 CAD，结果做不出一个正确的产品图。
> 现在只要产品外观图，能提取 CAD 的外观尺寸足够了」。本文=反思 + 方法总结，**今后凡"出图"先分型**。

## 1. 两级分型（先问"这张图要干嘛"，再决定动用什么链）

| | Tier 0 外观图（提案/目录/one-pager） | Tier 1 工程验证图（规格表/装配说明/对外 FINAL） |
|---|---|---|
| 几何依据 | **已文本化的包络与版式数字**（39.800×22.500×90.500、O1–O9+五条确认、107 的 placement/电池盖=底部） | 完整 STEP/BREP 网格化 + 真实 BREP 电池盖 + 8 视图 + 干涉结论 |
| 输入动作 | **零新文件**——truth 文档里已有全部所需 | 拉 STEP 全文、OCP 网格化、遮挡裁决（15.18mm³ HOLD）、105 §7 九步 |
| QA | 剪影 bbox 比例（正拍 0.44；25° 侧视剪影 ≈0.50，容差 ±6%）+ 要素清单 8 项 + 红项检查，**~5 分钟** | `09_VisualMethod` 100 分制 ≥95；`QA_ledger` K1–K14 全量 |
| 用途上限 | 视觉方向稿；**不得**写工程尺寸/兼容性/装配承诺 | 过闸门并经用户点头才可对外 FINAL |

**规则：Tier 0 永不等 Tier 1。** 只有当用户要"工程级/规格图"，或某要素在文字里根本没有（如背面、卡扣细节）时，才升级到 Tier 1 并说明缺什么。

## 3. Tier 0 三步法（本轮已跑通一次）

1. **锁输入**：包络比例（39.8:22.5:90.5 → 正拍 0.44 / 25° 剪影 0.50）；版式顺序自上而下 =
   大圆盘(内含斜向手动旋钮条) → LED 小点(暂定) → 中部圆形功能键 → [LOGO 刻字=A版/干净=B版] → 底部电池盖恰 3 道细浅横纹；
   材质语言 = 浅银灰阳极氧化铝壳+金属亮边+棕红细纹塑料面盖（**不是木头**）；
   禁项 = 螺丝/接口/键盘/摄像头/下部臆造圆形结构/坐标轴/盖跑顶部（K13）。
2. **约束生成**：数字和顺序写进 prompt，一次出 A/B 两版（`.scratch/`，不进 git）。
3. **数值自 QA**：PIL 量剪影 bbox 比例，超容差→只重生成**一轮**；清单核对 8 要素；红项=0 才呈现。
   连续两轮不过 → **降级提问**（只列 1 个最小缺失文件），不得继续循环——这是 session4 的教训。
