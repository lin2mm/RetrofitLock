# 00_meta directory structure

This file provides a focused guide to the `00_meta/` directory, which contains the repository's operational and methodological backbone.

## Purpose

`00_meta/` is the center of the repo for:

- project history
- method notes
- cross-session logs
- naming rules
- product truth and constraints
- scripts for maintenance and analysis
- intake and archival tracking

## How to read this folder

Use the following order for new work:

1. `META.md` — repo rules and governing constraints
2. `SESSION_BOOTSTRAP.md` — session setup and boundaries
3. `PRODUCT_TRUTH.md` — product-grounded facts
4. `METHOD_CURRENT.md` — current authoritative method page
5. `REQUEST_FILES.md` — source file requirements and references
6. `REUSABLE.md` — prior work that can be reused
7. `HANDOFF.md` and `session_log.md` — progress and context
