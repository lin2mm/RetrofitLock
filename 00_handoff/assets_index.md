## F. 怎么把文件送进这个沙盒（重要）

**本沙盒只有 `github.com` / `api.github.com` / `codeload` / npm / PyPI 通；Google Drive、Figma、Dropbox、
fonts.gstatic、raw.githubusercontent、各 CDN 全部不通（实测返回 000）。** 所以：

1. **首选：Arena 聊天里直接上传附件。** 图片/文件会进到我的工作区，我能读图、能转格式。
   单条消息多塞几张没问题；建议按上面 ID 分组发（例：这一条只发 P1，下一条只发 P2）。
2. **视频（P2）**：先在会话里传一次试试；如果不便传，用**抽帧**代替 ——
   在你本机执行（没有 ffmpeg 就用手机逐帧截图，20–30 张足够）：
   ```bash
   ffmpeg -i 半成品视频.mp4 -vf "fps=1,scale=1600:-1" -q:v 2 frame_%03d.jpg
   ```
   把 `frame_*.jpg` 打成 zip 或直接分批发我。我能从帧里读出真实几何，不需要整片。
3. **设计稿源文件（P1）**：给我**导出的 PNG（≥1600px、含透明底最好）+ 一张标注了尺寸/材质的截图**即可；
   `.ai/.psd/.blend` 我这边没有相应软件，别浪费时间传源文件。
4. **大文件兜底**：若某文件实在传不进来（超过 25MB），在你本机执行
   `base64 -i file.zip | split -b 900k - part_` 生成若干文本片段，把片段内容贴给我，
   或存成 Drive 里的 `.txt` 再把内容复制给我，我在沙盒里重组。**只在 1–3 都不行时才走这条。**
5. 你也可以让**别的 session** 把资料 push 到 `lin2mm/RetrofitLock` 某个分支（如 `assets/session3`），
   我从这边 `git fetch` 下来 —— 这是最省事的批量通道，适合 session 4 网站源码那种一大坨。
